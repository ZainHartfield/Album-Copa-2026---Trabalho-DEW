Sobre Este Projeto

📝 HTML Semântico

Usamos tags semânticas como <header>, <nav>, <main>, <section> e <article> para descrever o significado do conteúdo.

♿ Acessibilidade

Adicionamos atributos como aria-label, aria-labelledby e alt em imagens para que leitores de tela entendam o conteúdo.

📱 Responsividade

O site funciona em celular, tablet e desktop usando CSS Grid e Flexbox com media queries para adaptar o layout.

✨ Animações

Adicionamos animações CSS para tornar a experiência mais interativa e visualmente atraente.

🖱️ Modal/Popup

Clique em qualquer figurinha para ver um zoom em um modal. Clique no X ou fora do modal para fechar.
